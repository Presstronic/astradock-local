# CIG/RSI Community Team request

This draft is ready to submit through the RSI Support portal. It is not submitted automatically because submission requires the owner's RSI account.

## Subject

Community-made AstraDock Local Blueprint Exporter — requested guidance for public source and binary distribution

## Message

Hello,

I am developing AstraDock Local, an open-source, community-made Electron desktop tool for Star Citizen players. The repository is public here:

https://github.com/Presstronic/astradock-local

The immediate purpose is a free, experimental, Blueprint Exporter-only build. Users run it locally to read supported `Game.log` files and generate a local JSON or CSV blueprint file for manual use with a separate service. It does not modify the game, inject into the game, automate gameplay, access RSI accounts, upload raw logs, or distribute Star Citizen game files.

The application is clearly labeled as unofficial and community-made, including this notice:

“AstraDock Local is an unofficial, community-made Star Citizen tool. It is not affiliated with, endorsed by, sponsored by, or licensed by Cloud Imperium Games or Roberts Space Industries. Star Citizen and all related marks, logos, characters, and content belong to their respective owners.”

I would appreciate written guidance on the following:

1. Is it acceptable to publish this source repository and free Windows/Linux binaries for this local log-reading tool under the description above?
2. Is there specific disclaimer, attribution, or notice wording and placement you require in the desktop application, README, GitHub releases, and screenshots?
3. May the application or repository use any Fan Kit logos, screenshots, artwork, fonts, or other imagery? If so, does the current Fan Kit Agreement cover redistribution inside a public downloadable desktop application, and what attribution is required?
4. Are there restrictions or permissions I should understand before any future optional local inspection of installed game data? This is only exploratory at present and is not included in the current release.
5. Are there any naming, icon, packaging, or distribution practices you recommend to avoid confusion with an official CIG/RSI product?

I understand that this request is not approval to use any CIG/RSI content before written permission or applicable Fan Kit terms are confirmed. I will keep the current project on AstraDock-owned branding and avoid distributing game files or extracted assets.

Thank you.
