# CIG/RSI community disclosure guidance

This is a practical project policy based on the current official CIG/RSI guidance. It is not legal advice, and the official policies can change.

## Current project treatment

AstraDock Local is an unofficial, community-made Star Citizen tool. The app and public project should display:

> AstraDock Local is an unofficial, community-made Star Citizen tool. It is not affiliated with, endorsed by, sponsored by, or licensed by Cloud Imperium Games or Roberts Space Industries. Star Citizen and all related marks, logos, characters, and content belong to their respective owners. Official site: https://robertsspaceindustries.com/.

The notice appears in the Exporter and Settings views and in the README. Release notes and any project website or promotional material should use the same meaning. The project must not describe AstraDock as official, licensed, endorsed, sponsored, or affiliated.

## Imagery and other RSI content

The current application uses AstraDock-owned branding and does not bundle Star Citizen logos, screenshots, concept art, game assets, music, fonts, or other RSI/CIG imagery. This is the lowest-risk default for a downloadable software tool.

The official Fan Kit contains logos and other assets, but access requires accepting the Fan Kit Agreement and following its terms. That agreement should be reviewed for software redistribution specifically before any Fan Kit asset is committed to this repository or packaged into a release. Do not redistribute installed game files or extracted game assets.

If an approved image is ever used in project imagery, preserve the required attribution and community notice from the applicable Fan Kit terms. The official FAQ describes a “Made by the Community” notice for imagery and requires attribution/trademark treatment; do not assume that guidance is a software license.

## Distribution policy pending written guidance

The project is public and releases free, experimental Blueprint Exporter builds. The exporter reads supported local `Game.log` files and does not upload raw logs. Any future reading of installed game data remains exploratory and is not represented as authorized by CIG/RSI.

Before expanding the distribution or adding RSI/CIG imagery, obtain written guidance from the RSI Community Team about:

- public source-code hosting and free downloadable Windows/Linux binaries;
- a community-made local tool that reads `Game.log` without modifying or injecting into the game;
- the required disclaimer and attribution placement in the app, repository, releases, and screenshots;
- use of Fan Kit imagery, logos, fonts, or other assets in a public desktop application;
- whether future optional local inspection of installed game data is permitted and under what boundaries.
